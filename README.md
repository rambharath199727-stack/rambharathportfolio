# RamBharath Baskar · Portfolio

Personal portfolio of **RamBharath Baskar**, Software / Web Developer in Chennai. I build admission and counselling portals, admin dashboards and API integrations for Tamil Nadu government universities with PHP, Laravel and MySQL.

**Live site:** https://rambharath199727-stack.github.io/rambharathportfolio/

## Features

- Tamil / English language toggle
- Light and dark themes
- Classic serif typography with letter-by-letter heading animations
- One-page printable resume (`resume.html`, "Download PDF" button)
- Responsive layout for phones, tablets and desktops
- Plain HTML, CSS and JavaScript, with no build step

## Files

| File | What it is |
|---|---|
| `index.html` | The portfolio |
| `resume.html` | The resume page |
| `serve.ps1` | Optional local server for Windows (`powershell -ExecutionPolicy Bypass -File serve.ps1`, then open http://localhost:8080/) |
